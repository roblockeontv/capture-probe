# Eyeline capture probe

Diagnostic harness for the Eyeline project, not the product. Settles whether a browser camera works inside an installed home-screen web app, and whether occluded window capture works on a desktop. Open `EYELINE-capture-probe.html`, add to home screen, open from the icon, press Test camera, copy the report.

The file hashes are banked in the project ledger; the page prints the sha256 it was served.
